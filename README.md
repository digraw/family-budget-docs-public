This repository contains the public user documentation for **Family Budget
Tracker**, covering the React web application and native Android application.

## Distribution status

The Android app is available as a signed direct APK. A separate Google Play
build is in closed testing. Production access has not been requested, and the
app is not represented here as available on the Google Play Production track.

## Documentation map

- **`index.html`**: Documentation landing page with feature highlights.
- **`getting-started.html`**: Seven-step onboarding guide.
- **`user-manual.html`**: Web and Android feature manual.
- **`mobile-app.html`**: Android installation, privacy, and feature guide.
- **`magic-drop-guide.html`**: Google Drive and Gmail statement-ingestion setup.
- **`faq.html`**: Plans, security, privacy, and accounting questions.
- **`videos.html`**: Video walkthroughs.
- **`DEMO_SCRIPT_FINAL.md`**: Synthetic-data capture checklist for public media.
